# Türk Masalları Dünyası

Bu proje Programlamaya Giriş dersi vize ödevi için hazırlanmıştır.

Web sitesinde 10 farklı Türk masalı bulunmaktadır. Kullanıcılar istedikleri masalı seçebilir ve butonlarla masal metinlerini açıp kapatabilir.

Web sitesinde HTML, CSS ve JavaScript kullanılmıştır.

## Web Sitesi Nasıl Açılır?

index.html dosyası bilgisayara indirilir ve Safari veya Chrome gibi bir tarayıcıda açılır.

Web sitesi internet bağlantısı olmadan çalışabilir.

## Sunum Videosu

YouTube video bağlantısı sunum hazırlandığında buraya eklenecektir.
